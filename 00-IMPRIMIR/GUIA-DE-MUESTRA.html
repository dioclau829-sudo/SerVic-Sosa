✔ Antes de presentar (30 segundos)

▢ La página abierta en el celular con datos (o el wifi del lugar).

▸ Cómo imprimir y doblar el folleto

1
Imprimir: A4 apaisado, a doble cara, activando "Voltear por el borde corto" (es la clave para que la contraportada quede atrás).
2
Doblar 1: el tercio derecho hacia atrás. La portada queda afuera.
3
Doblar 2: el tercio izquierdo hacia atrás. Listo: 6 paneles, se lee Portada → Para qué sirve → Con qué la fabriqué → El catálogo → El panel → Cómo lo logré.

▸ Tu guion (2 minutos)

1. "Buen día, les presento Servic PC, una página web de un taller de reparación de computadoras en Wanda."
2. "La página tiene tres cosas: muestra mis servicios, vende repuestos con fotos y precios, y recibe pedidos por WhatsApp con un botón."
3. "La armé con HTML para la estructura, CSS para el diseño y JavaScript para que funcione: el catálogo, los filtros y el panel."
4. "Lo más difícil fue el panel de administración: que yo pueda agregar productos y aprobar reseñas sin tocar el código."
5. "Las reseñas de los clientes llegan a una planilla de Google y me avisa una campana: verde si es buena, roja si es mala."
6. "Usé inteligencia artificial como ayuda para corregir el código; el diseño, los precios y los textos son míos."
7. "Ahí les dejo el link y el código QR, por si quieren verla."

▸ Demostración en vivo (1 minuto)

  1. Portada: el carrusel de trabajos que pasa solo, con las flechas.
  2. Productos: tocá un filtro, después una foto (se agranda) y después el botón de WhatsApp.
  3. Reseñas: dejá una opinión de prueba y mostrá que queda "pendiente".
  4. Panel: entrá con la clave, mostrá la campana y aprobá esa reseña.
  5. Planilla: abrila en el celu y mostrá la fila que se acaba de crear.

? Preguntas que te pueden hacer

¿Qué es HTML, CSS y JavaScript? HTML arma la página, CSS la decora y JavaScript la hace funcionar.
¿Qué usaste para los íconos? Font Awesome, el mismo kit que figura en el material de la materia.
¿Cómo armaste el catálogo? Los productos están en un arreglo de objetos y una función dibuja las tarjetas. Agregar uno es escribir una línea.
¿Cómo llegan las reseñas? A una planilla de Google, usando Google Apps Script como servidor gratuito.
¿La IA hizo la página? Me sirvió para corregir errores y ordenar el estilo. El contenido y el diseño son míos, y lo puedo explicar.
