Tu navegador está bloqueando el guardado

Esta versión del panel necesita guardar datos en el navegador (localStorage) para que los cambios que hacés se guarden. Estás abriendo la página con doble clic, y algunos navegadores bloquean el guardado en ese caso.

Cómo resolverlo: abrí la carpeta con un servidor local, en vez de hacer doble clic. Podés usar el Live Server de Visual Studio Code (botón derecho sobre el archivo → Open with Live Server) o, en una terminal, escribir python -m http.server 8080 y entrar a http://localhost:8080/panel.html.

Revisión de reseñas

Las reseñas que escriben los clientes en la página llegan acá. Solo las que están aprobadas se ven en el sitio: las demás quedan ocultas.

Las reseñas que llegan desde el formulario de la página se guardan en este navegador. Para que le lleguen desde otras computadoras hay que usar un servidor (por ejemplo Python) o un formulario externo. Está explicado en la guía.

Publicar los cambios en el servidor

Los cambios que hacés se guardan en este navegador, así que los ves al instante pero todavía no los ven los demás. Para publicarlos: exportá el archivo datos.json, copialo en la carpeta assets/js/ de la página y subilo al hosting.
